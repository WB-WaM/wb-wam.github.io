# Resource button brand assets

Retrieved 2026-09-17. All SVG files passed `xmllint --noout`.

- `arxiv.svg`: Simple Icons arXiv brand mark, 24 x 24 viewBox.
  - Display fill set to arXiv red (#B31B1B); original geometry unchanged.
  - Exact download: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/arxiv.svg
  - Repository page: https://github.com/simple-icons/simple-icons/blob/develop/icons/arxiv.svg
  - Simple Icons is CC0 1.0 Universal. License retained as `Simple-Icons-LICENSE.md`; trademark rights remain with the respective owners.
- `GitHub_Invertocat_Black.svg` and `GitHub_Invertocat_White.svg`: official GitHub Invertocat standalone mark.
  - The website uses the black asset as `github.svg`, rendered white on the dark button using CSS.
  - Official brand page: https://brand.github.com/foundations/logo
  - Exact official archive: https://brand.github.com/GitHub_Logos.zip
  - Archive paths: `GitHub Logos/SVG/GitHub_Invertocat_Black.svg` and `GitHub Logos/SVG/GitHub_Invertocat_White.svg`.
  - GitHub retains trademark/copyright rights. The official page permits using the Invertocat as a social button linking to a GitHub profile or project. Preserve the supplied shape and color; use secondary placement.
- `huggingface.svg`: official full-color Hugging Face standalone face mark, 256 x 256 viewBox.
  - Official brand page: https://huggingface.co/brand
  - Exact download: https://huggingface.co/datasets/huggingface/brand-assets/resolve/main/hf-logo.svg?download=true
  - Original file page: https://huggingface.co/datasets/huggingface/brand-assets/blob/main/hf-logo.svg
  - The official brand page expressly provides these assets for use in projects; no separate open-source license was displayed there. Do not label it as CC0.

These are supplied for service/resource links, not as WB-WAM's own logo.

## Website favicon

The active project mark is the purple **02 Chamfer** WB lettermark, selected
on 2026-09-26 from the project's image-generated design candidates. The
original PNG artwork was mechanically cropped and resized; its letterforms
and colors were not redrawn. All exported PNGs retain true alpha transparency.

- `wb-chamfer-v1-wordmark.png`: purple WB plus black WAM, used in navigation.
- `wb-chamfer-v1-16.png`, `wb-chamfer-v1-32.png`,
  `wb-chamfer-v1-180.png`, `wb-chamfer-v1-512.png`: WB-only square-canvas icons.
- `wb-chamfer-v1.ico`: 16, 32, 48, and 64 px browser fallbacks.
- The root `favicon.ico` and `apple-touch-icon.png` are fallback copies.

Versioned filenames avoid reusing the previous blue-WB icon URLs.
The former `wb.svg`, `wb-*.png`, and `wb-v1.ico` assets remain available
but are no longer referenced by the page.

The legacy robot favicons were rendered locally from the existing U+1F916 robot
emoji using the macOS Apple Color Emoji font on 2026-09-25. The font file
is not redistributed. `robot-16.png` and `robot-32.png` remain as legacy
assets but are no longer linked by the site. They are not original WB-WAM
artwork or Simple Icons assets.
